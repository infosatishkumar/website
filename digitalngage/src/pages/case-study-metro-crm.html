The problem

Leads everywhere. Control nowhere.

01

Leads everywhere

Enquiries came from Facebook Lead Ads, Google Ads, IndiaMART, the website and WhatsApp. Each lived in a different inbox or spreadsheet — and some were never called back.

02

Quotes built by hand

Every quotation for sandwich panels, purlins or roofing sheets was calculated and typed manually. Weights, areas, GST and numbering were easy to get wrong.

03

No shared picture

Management couldn't see who handled which customer, which leads had gone cold, or what had been promised. Two agents sometimes chased the same buyer.

Inside the app

Designed for a team that sells all day.

Key decisions

Engineered to be fast & safe.

{{icon:rocket}}

One file, zero build step

The whole front end ships as a single HTML file. The client's team deploys an update by uploading one file to shared hosting — no build tools, no servers to manage.

{{icon:bolt}}

Save only what changed

The app computes a delta of what each user changed and sends just that. A server-side lock stops simultaneous saves overwriting each other.

{{icon:shield}}

Notes are never overwritten

Follow-up notes are append-only and de-duplicated by key, so two agents writing at once can never erase each other's history.

{{icon:chart}}

Compress the big download

With thousands of leads the initial sync grew to ~11 MB. Gzipping cut it to ~1.85 MB, so the CRM opens quickly even on mobile data.

Hard problems, solved

Bugs that real teams actually hit.

Problem

The banner that wouldn't go away

Agents kept seeing "Changes not saved yet", even when idle. Server space and plan limits looked fine.

The fix

The network log showed save requests returning 403 from the host's CDN, not the app — its firewall treated rapid saves as an attack. Turning the CDN off for the CRM domain fixed it for every agent.

Problem

Duplicate leads leaked customers

When an agent added a lead that already belonged to a colleague, the existing customer appeared in their list.

The fix

The duplicate check now stops the save and shows a clear message naming the customer and the agent already handling them. Admins still see everything.

Problem

A quotation that couldn't be updated

Switching a quote between the two companies changed its ID prefix, and the update was rejected.

The fix

Edits now keep the original quote number and swap only the company prefix — and the linked job card follows the change.

Outcome

Every enquiry, one place.

Every enquiry now lands in one place, is checked for duplicates and reaches an agent automatically. Over 6,000 leads and 27,000 follow-up notes live in a single MySQL database instead of scattered sheets.

Quotations, job cards and payments are connected to the lead that started them, so management can follow any order from the first call to dispatch.
